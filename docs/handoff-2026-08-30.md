## 2. 확정된 원칙 — 재논의 금지

**어댑터는 CLI의 인터페이스를 API와 같게 만드는 도구다.** 수단은 이 순서: ① 환경 제약 ② 런타임 노브 ③ 응답 경로의 코드(상쇄 래퍼)
④ ~~프롬프트 주입~~ **금지**.

**옵션은 약속이고 프롬프트는 부탁이다.**

| 상황 | 해야 할 것 |
|---|---|
| 슬롯이 있다 | 슬롯으로 보낸다. 산문 금지 |
| 슬롯이 없고 코드로 실현·검증 가능 | 코드로 실현 (이미지 `n` 병렬 턴, app-server `size`/`mask`/포맷 실현이 그 예) |
| 둘 다 아니다 | direct가 거절하면 같은 봉투로 거절, direct가 수용하면 수용하되 "미적용"을 계약에 명시 |
| 호출자가 보내지 않았다 | 넣지 않는다 |

**절대 하지 말 것: 수용해놓고 전달하지 않으면서 응답에 적용됐다고 에코하는 것.**

**패리티의 권위는 direct API 실측이다.** 문서·SDK 타입·기억이 아니라 라이브 응답. 봉투(status/type/param/code/message)와 **보고 순서**까지
같게 한다. 실측 원자료는 `docs/conformance-matrix.md` §5.5.x에 날짜와 함께 남긴다.

**이미지 라우트는 능력 격차로 일괄 거절하지 않는다** (사용자 결정 2026-08-29): Images API에 대응하는 CLI 모델이 없는 게 정상 조건이므로,
프록시는 direct에 최대한 가까운 결과를 코드로 낸다. 백엔드 이미지 모델(`gpt-image-2-codex`) 자체가 거절하는 것(`background: transparent`,
`input_fidelity`)만 그 봉투로 거절한다. `x_proxy_image_route`는 direct가 거절하는 유일한 수용 키(의도된 확장, 유지).

**분량은 판정 축이 아니다** (A/A 변동 median 13.4%). LLM 판정은 게이트가 아니다.

## 5. 반복해서 값을 한 규율

- **핸드오프·리뷰·기억의 "확인됨"은 가설이다.** 저장소에 증거 파일이 없으면 다시 잰다 — 이번엔 "슬롯 4개 존재"가 절반만 맞았고
  (백엔드 모델이 2개를 거절), "dall-e-2 기본값"은 소멸한 모델이었다.
- **모든 게이트를 변이로 양방향 확인한다.** src를 stash하고 새 테스트가 빨간불 나는 것을 본다. 이번 세션의 커밋 전부가 이 절차를 거쳤다.
- **direct 프로브는 확실한 무효값을 같이 싣는다.** 공백 프롬프트 `"   "`를 "거절될 것"이라 짐작하고 보냈다가 생성·과금됐다.
  벤치 direct 팔의 `transparent` 행도 전제가 틀려 1건 과금됐다.
- **리뷰 중에는 워킹트리를 옮기지 않는다.** 2차 리뷰 때 옮겼고 Codex가 핀 blob에서 다시 읽어 버텼지만 운이었다. 3차부터 고정.
- **리뷰 지적은 코드에서 재확인한 뒤 고친다.** 13건 중 전부 맞았지만, 한 건(Claude의 그레이스케일 마스크 가설)은 리뷰어 스스로 반박했다.
- **파이프 종료 코드는 마지막 단계 것**, `pgrep -f`는 자기 자신을 매칭, macOS엔 `timeout` 없음, `codex`는 셸 함수(spawn엔 `/opt/homebrew/bin/codex`).
- **패키징 규칙은 검사로 존재한다** (`scripts/package-adapter.mjs`): 런타임 의존성 allowlist `['sharp']`, direct provider egress 금지,
  `verify-runtime-boundary`는 런타임 소스의 `fetch(` 금지 — 실현 모듈이 걸려 원격 URL 마스크는 400으로 정리했다.
