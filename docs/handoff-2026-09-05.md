## 2. 확정된 원칙 — 재논의 금지

**어댑터는 CLI의 인터페이스를 API와 같게 만드는 도구다.** 수단은 이 순서: ① 환경 제약 ② 런타임 노브 ③ 응답 경로의 코드
④ ~~프롬프트 주입~~ **금지**. **옵션은 약속이고 프롬프트는 부탁이다.**

| 상황 | 해야 할 것 |
|---|---|
| 슬롯이 있다 | 슬롯으로 보낸다. 산문 금지 |
| 슬롯이 없고 코드로 실현·검증 가능 | 코드로 실현 |
| 둘 다 아니다 | direct가 거절하면 같은 봉투로 거절, direct가 수용하면 수용하되 "미적용"을 `docs/conformance-matrix.md`에 **선언** |
| 호출자가 보내지 않았다 | 넣지 않는다 |

**절대 하지 말 것: 수용해놓고 전달하지 않으면서 응답에 적용됐다고 에코하는 것.**

**응답 경로의 백스톱은 거절하지 수리하지 않는다.** 모델이 쓰지 않은 답으로 고쳐 쓰지 않는다 — 앞 공백 strip, 객체형 인자의 stringify,
`{"input": …}` 감싸기, parse+stringify 재직렬화 전부가 "수리"였고 전부 지웠다. **런타임이 쓴 바이트가 답이다** — 모든 표면, 두 경로 모두.
JSON 값 표면(Messages `input`)에서는 `RawJson`/`stringifyJson`으로 바이트를 접합한다.

**판정할 수 없는 것은 통과시킨다(`unjudged`)**: 컴파일 안 되는 스키마, `$async`, 미해결 `$ref`, 그리고 double이 정확히 못 담는 숫자를 실은
텍스트의 위반(유효 숫자 기준 — 0 패딩은 부정확이 아니다). 스키마 강제는 클라이언트가 약속을 건 곳에서만(`strict: true`, Messages 구조화 출력).

**출력 한도 예외**: 런타임이 `max_tokens`를 보고한 턴은 어떤 완료 규칙도 판정하지 않고, direct가 전달하는 모양으로 전달한다
(Chat `length`, Responses `incomplete`, Messages `max_tokens` + 본문엔 완성 멤버·스트림엔 마지막 블록만 열어 둠). app-server는 stop reason이 없어 조각을 항상 거절(선언).

**표는 계기 뒤에 쓴다.** 미러의 첫 단계는 direct 실측 행 추가(`review-artifacts/stage2/report.md` M5–M9). 두 표본은 "결정적"의 증거가 아니다
(M8 정정: Chat 빈 `tools`+`required`는 생성 단계에서 비결정).

**결함 수정에 기능 개발 금지. 수정이 수정을 부르면 설계 과제.**

### 4-10. 갱신 락의 원자성 — advisory lock 설계 과제 (작음, 설계)

기록: `docs/design-task-refresh-lease-atomicity.md`(계약 행이 가리키는 파일). codex r53이 실측한 잔여 둘: `unlinkOwnLock`의 '소유자 읽기 → 경로로 unlink'와 갱신 저장의 '소유자 확인 → rename'(r53 Fable 뒤 세대 비교 대신 보유자 확인)은 check-then-act라, 그 틈에 lease 탈취가 끼어들면 남의 락을 지우거나 탈취된 갱신이 저장된다(FIFO로 틈을 벌려 재현). 현재 코드에서 탈취는 lease(60s)보다 긴 정지가 fetch 상한(30s) 도중에 있어야 열리므로 프로세스 정지가 전제이고, 계약 행이 그렇게 범위를 적어 두었다. 닫으려면 파일 lease 대신 핸들에 묶인 advisory lock(flock 류 — Node 표준 라이브러리에 없어 네이티브 의존성 또는 별도 설계 필요)이나 fencing 토큰이 필요하다. 릴리스 후 설계 과제.

## 5. 반복해서 값을 한 규율

- **리뷰 라운드는 직전 수정을 본다.** 수정은 새 표면이고, 15·16·20·21라운드가 실제로 직전 수정이 만든 결함을 찾았다(caused와 surfaced를 구분해 적는다).
- **변이는 대상 존재부터 단언한다** — 앵커 카운트 ==1, 컴파일, 관측 가능한 변화, 프로브가 무변이 코드에서 판별함을 먼저 보인다. macOS엔 `timeout`이 없어 조용히 빈 출력이 났다.
- **측정과 일치하는 판독일수록 계기를 의심한다.** 두 표본의 500을 "결정적"이라 적었고, 최종 parity가 그것을 깼다.
- **한 멤버를 고칠 때 같은 리더의 형제 멤버를 전수 확인한다.** `strict`만 자기 위치로 스코프하고 `name`/`parameters`는 교차 판독으로 남겼다.
- **수리 함수는 판별을 부수효과로 겸하고 있을 수 있다.** 네이티브 전송기의 수리를 지우자 "완료 신호를 낼지"의 판별이 사라져 회귀 1건 — 명시적 `parsesAsJson`으로 살렸다.
- **codex 좌석은 OpenAI 콘텐츠 분류기에 걸릴 수 있다**(20라운드 두 번 중단, 같은 패킷이 다른 라운드에선 통과). 기록하고 Claude 좌석으로 라운드를 마친다.
- **라이브 parity는 dist 변이와 동시에 돌리지 않는다.** 산출물은 `review-artifacts/`(스크래치패드는 통째로 비워진다).
