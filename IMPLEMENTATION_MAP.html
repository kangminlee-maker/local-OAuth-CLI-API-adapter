별도 /local/cli/sessions 표면은 provider-compatible 응답 재구성을 피하고, Codex app-server 또는 Claude stream-json session의 raw event를 작은 SSE envelope로 전달하는 native chat API입니다.

OpenAI provider-compatible text/tool과 Images API 표면의 기본 hot path는 codex-backend입니다. proxy-codex는 text/tool을 ChatGPT Codex backend SSE에 직접 매핑하고, Images API는 backend Responses image_generation tool의 image_generation_call.result를 OpenAI Images schema로 감쌉니다. native local chat은 Codex app-server를 유지합니다. access token은 만료 전 또는 인증 실패 후 refresh token으로 갱신하며, refresh token이 만료·폐기·재사용된 경우에만 재로그인을 요구합니다.

proxy-codex의 provider error policy, 이미지 벤치 계획, Claude 한국어 incident는 direct provider 기준 targeted closure에서 모두 95점 이상을 통과했습니다. 이미지 image2_via_gpt55는 full direct 비교에서 backend image_generation tool 결과가 없는 completion이 12건 재현됐고, 이후 backend-only no-image semantic retry와 transient fetch retry를 추가했습니다. 실패 12개 targeted closure에서는 no-image 실패가 0건으로 줄었습니다. 최신 타임라인 기준 이미지 속도 병목은 proxy wrapper나 tool 선택 전 단계가 아니라 Codex image generator 결과 대기입니다. Codex app-server native imageGeneration 경로도 같은 단일 케이스에서 64.5초로, backend Responses tool 61.4초보다 빠르지 않았습니다. backend tool field에는 action, size, quality, output_format, output_compression, background, moderation, input_fidelity, input_image_mask를 직접 전달합니다 — 옵션은 슬롯으로 보내고 산문으로 되풀이하지 않습니다(2026-08-29 tool-slot 프로브: 백엔드는 선언을 엄격 검증하며, background: transparent와 input_fidelity는 백엔드 이미지 모델 gpt-image-2-codex가 거절하므로 그 거절을 그대로 전달합니다; pnpm probe:codex-image-tool-slots). 호출자 프롬프트를 정규식으로 읽어 발동하던 산문 규칙(정사각형·원·중앙 배치, "no text", "white background", flat/solid/vector 스타일, 색상 교체·배경 전용 edit 보존)은 2026-08-29에 전부 제거했습니다 — API 필드에 대응되지 않는 이미지 조향이었고, 벤치 문장에만 12줄이 붙던 원인이었습니다. 이제 image2_via_gpt55는 route hint가 없으면 호출자 프롬프트를 그대로 보냅니다(주입 0자). flat/vector reference-style은 edge-preserving PNG flat postprocess 적용 후 proxy 최저 96점으로 통과했고, 같은 run의 direct는 최저 89점으로 실패했습니다. 이미지 runtime transform PoC에서는 JPEG photoreal은 canonical 생성 후 runtime 변환이 47.1% 시간으로 빨랐지만, flat WebP는 158.9%로 느려 format/style별 capability rule이 필요합니다. 분류별 5회 format discovery에서는 textOrLogoGraphic WebP, photorealRaster WebP/PNG/default, productIdentity PNG/WebP/default가 통과했고, referenceOrEdit와 unknownHybrid는 포맷보다 품질 안정화가 먼저입니다. 추가 targeted discovery에서는 simpleFlatGraphic이 prompt 다양화 후 모든 포맷에서 min 95 미만이라 rule 승격을 보류했고, photorealRaster는 WebP가 가장 균형적인 후보입니다. 프롬프트만으로 format/geometry route를 안정적으로 판정하기 어려운 케이스를 위해 proxy-only x_proxy_image_route 확장 필드를 추가했고, 이 필드는 provider parity가 아닌 proxy enhanced 벤치 행으로 분리합니다.

런타임 흐름

1. API 수신 startLocalApiProxy가 OpenAI Chat, OpenAI Responses, OpenAI Images, Anthropic Messages 호환 요청을 받습니다.
2. 요청 정규화 provider별 입력을 내부 메시지, 도구, 이미지 참조, 응답 형식, 스트리밍 모드, effort, verbosity로 변환합니다.

5. Native chat /local/cli/sessions는 provider 응답으로 재구성하지 않고 raw CLI event를 cli.event SSE envelope로 전달합니다.
